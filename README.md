# POFINO — Moniteur institutionnel MTMD

Dépôt dédié à la présentation POFINO (16 diapositives), indépendant de l'application `pofino-v5`.

## Mise en ligne

Le site est statique. Le fichier de présentation doit être placé à la racine sous le nom `index.html` : `POFINO_Moniteur_Site_index.html` (fichier HTML autonome, images intégrées, narration vocale navigateur).

Dans Vercel : **Add New > Project > Import Git Repository > Matthprudd/pofino-moniteur-mtmd**. Framework : **Other**, répertoire racine : `./`, commande de build : aucune. La connexion Git active les déploiements suivants automatiquement.

**À noter** : la narration dépend des voix installées sur le navigateur; le contenu présente une aide à la planification et ne constitue pas une homologation MTMD.
